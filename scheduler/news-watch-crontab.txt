# Event-driven RSS news watcher for nba-scenario-bot.
# Install manually with:
#   crontab scheduler/news-watch-crontab.txt
# Keep the Mac awake while unattended with:
#   caffeinate -s
#
# Runs every five minutes between 10:00 and 23:55 ET. The phase is cheap on
# no-hit runs: RSS diff only, no qual LLM, no Telegram alert, no demo cycle.
# Triggered runs call scheduled-demo-cycle, which forces demo mode and never
# sets live gates.
# Each command writes one timestamped stdout/stderr log under logs/.

CRON_TZ=America/New_York
REPO=/Users/ellingtonfagan/Downloads/nba-scenario-bot
LOG_DIR=$REPO/logs

*/5 10-23 * * * mkdir -p $LOG_DIR && cd $REPO && NBABOT_EXECUTION_MODE=demo .venv/bin/ksobot news-watch >> $LOG_DIR/news-watch-$(date +\%Y\%m\%dT\%H\%M\%S).log 2>&1
